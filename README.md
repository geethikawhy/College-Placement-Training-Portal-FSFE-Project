# College Placement Training Portal

*A centralized platform for organized campus placement preparation.*

## About the Project

The College Placement Training Portal is a frontend web application designed to help students organize and access placement preparation resources in one place. It brings together training schedules, learning materials, practice activities, and placement announcements.

## Objectives

- Provide easy access to placement training schedules.
- Organize learning resources in one platform.
- Support aptitude, logical reasoning, and coding practice.
- Keep students updated with placement announcements.
- Help students track their preparation activities.

## Key Features

- Student Dashboard
- Training Schedules
- Learning Resources
- Practice Activities
- Placement Announcements
- Preparation Progress Tracker

## Technologies Used

- HTML
- CSS
- JavaScript
